# 平台实测手册 — 官方网申系统核实岗位（防误报核心）

> 目的：workfind 判定"已开放"的唯一可靠依据 = **打开官方网申系统，数出用户地区的岗位数**。
> 新闻/公告只能证明"集团启动"，不能证明"用户地区有岗"（2026-08 航发误报教训：集团 7/30 启动，成都单位岗位为 0）。

## 通用判断信号

| 信号 | 判定 |
|:----|:----|
| 招聘单位列表里**有用户地区单位**（如"四川公司"） | 可能可投，继续看岗位数 |
| 用**地区筛选**（工作地点/省份）点用户地区 → 出现岗位 | 🟢 已开放（本地区有岗） |
| 地区筛选后**无岗位** | 🟡 集团已启动，本地区岗位未上线，盯平台 |
| 主入口还是**上一届**内容（如 2026 暑期实习） | 🟡 未开放（当年还没开） |
| 岗位列表区**为空/无数据**（"没有找到相应的数据"） | 🟡 未开放 |
| 公告区无当年秋招公告、只有系统升级/春招 | 🟡 未开放 |

## 运营商平台操作手册（2026-08-10 实测验证）

### 中国电信 — job.chinatelecom.com.cn/wt/TELE/web/index
1. 打开校园招聘页 → 默认显示"招聘单位(N)"列表
2. 工作地点筛选点"展开全部" → 点用户省份（如"四川省"）
3. 判定：省份点后**单位列表变化/出现该省单位岗位** = 🟢；单位列表仍无该省单位 = 🟡（如 2026-08-10：14 家单位无四川公司，四川未上线）
4. 注意：电信"岗位陆续更新上线中"，四川公司可能后放，需持续盯

### 中国移动 — job.10086.cn
1. 首页 → 点"校园招聘"
2. 左侧单位导航（集团总部/省公司/专业公司/直属单位）找用户地区：如"四川公司""成都产业研究院""集团总部内审部（天津、武汉、成都）分部"
3. 点地区单位 → 判定：岗位区有数据 = 🟢；**岗位区为空/busy 无数据 = 🟡 未开放**（2026-08-10 实测：框架就绪但岗位空）
4. 公告区看有无当年秋招公告（2026-08-10 只有系统升级/春招公告 = 未开放）

### 中国联通 — zglt.zhaopin.com（智联专区）
1. 打开主入口 → 看标题：是"202X届校园招聘"还是"202X暑期实习生计划"
2. 标题是**上一届/实习计划** = 🟡 未开放（2026-08-10 实测：仍为"2026暑期实习生计划"）
3. 联通官网招聘栏目 chinaunicom.com.cn → 校园招聘 → 投递链接同样判断

### 中国铁塔 — zhaopin.chinatowercom.cn（官方唯一）
1. 打开 → 有防诈骗提示页（本网站为唯一招聘网站，笔试面试通知仅 @chinatowercom.cn / @italent.cn 邮箱）→ 点"我已阅读并同意"
2. 导航点"校园招聘" → 判定：列表有数据 = 🟢；**"没有找到相应的数据" = 🟡 未开放**（2026-08-10 实测）
3. 历史规律：每年 10 月中-11 月中报名，2027 届预计 2026 年 10 月开

## 反诈骗要点（实测时一并核对）
- 铁塔这类提示页本身就是官方渠道判据：**唯一官网 + 邮箱后缀**（@chinatowercom.cn）
- 任何"付费内推/保过/保证金/索要验证码"与官方无关（详见 anti-fraud.md）
