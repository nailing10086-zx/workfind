# 平台实测手册 — 官方网申系统核实岗位（防误报核心）

> 目的：workfind 判定"已开放"的唯一可靠依据 = **打开官方网申系统，数出用户地区的岗位数**。
> 新闻/公告只能证明"集团启动"，不能证明"用户地区有岗"（2026-08 航发误报教训：集团 7/30 启动，成都单位岗位为 0）。

## 通用判断信号

| 信号 | 判定 |
|:----|:----|
| 招聘单位列表里**有用户地区单位**（如"四川公司"） | 可能可投，继续看岗位数 |
| 用**地区筛选**（工作地点/省份）点用户地区 → 出现岗位 | 🟢 已开放（本地区有岗） |
| 地区筛选后**无岗位** | 🟡 集团已启动，本地区岗位未上线，盯平台 |
| 主入口还是**上一届**内容（如 2026 暑期实习） | 🟡 未开放（当年还没开） |
| 岗位列表区**为空/无数据**（"没有找到相应的数据"） | 🟡 未开放 |
| 公告区无当年秋招公告、只有系统升级/春招 | 🟡 未开放 |
| **第三方聚合站**（jobui/牛企/中公/高顿/超级简历）显示岗位 | ⚠️ 只作线索，**必须回官方系统核实**——聚合站常挂已下架的旧岗位（实例：jobui 显示中航党建岗"7小时前"，官方系统实为"已停用"） |
| **开放日/暑期实习公告**（"XX开放日/暑期实习生"） | ⚠️ **≠ 校招正式岗**，标注区分（开放日=提前批体验性质） |
| 官方系统岗位**无截止时间（长招）**且未停用 | 🟢 当届可投——判断看"是否停用/下架"，**不能只看发布年份**（实例：中航无人机 2026-06 发布的岗 2027 届仍可投） |
| 单位有开放岗但**按用户方向过滤后无对口岗** | ⚠️ 标"已开放但方向不匹配"，不标可投（实例：天翼云成都9岗中仅产品经理1个对口） |

## 浏览器前置（Chrome MCP 依赖 9222 调试端口）

### Chrome MCP（谷歌浏览器）——优先使用，可复用登录态

Chrome MCP 连到本机调试模式运行的 Chrome（CDP 9222），**能看到真实登录态、能点表单、能数岗位**。**建议优先用 Chrome MCP 而非 playwright**：登录态可复用（用户登录一次，投递/核实都能继续）。

**① 启动 Chrome（调试模式，独立 profile）**：

```bash
# 检查是否已在运行（返回 JSON 含 Browser 字段 = 可用）
curl -s -m 5 http://127.0.0.1:9222/json/version

# 未运行则拉起（独立 profile，不影响日常 Chrome）
"/c/Users/22174/AppData/Local/Google/Chrome/Application/chrome.exe" \
  --remote-debugging-port=9222 \
  --user-data-dir="C:/Users/22174/.chrome-devtools-profile" \
  --no-first-run --no-default-browser-check about:blank &
sleep 4   # 等端口就绪，再 curl 验证一次
```

**② 常用工具与操作路径**：

| 操作 | Chrome MCP 工具 | 说明 |
|:----|:----|:----|
| 打开页面 | `navigate_page` | 传 URL；返回当前页面标题 |
| 看页面结构 | `take_snapshot` | 返回可交互元素树（含 uid），是点击/填写的依据 |
| 点击 | `click` | 传 snapshot 里的 uid；大页面用 `includeSnapshot=true` 拿新树 |
| 填写表单 | `fill_form` | 一次填多个字段，优先用（比逐个 fill 快） |
| 页面列表 | `list_pages` | 确认当前有几个 tab/当前页 |

**③ 常见故障与处理**：

| 报错 | 原因 | 处理 |
|:----|:----|:----|
| `Could not connect to Chrome` | Chrome 没在跑/9222 未监听 | 按①拉起并 curl 验证 |
| `fetch failed`（curl 却通） | Chrome 刚被关/后台任务结束 | 重启 Chrome（用后台方式保持存活） |
| 页面 busy/岗位区空 | 页面在加载 或 岗位未上线 | 等 3-5 秒重新 take_snapshot；仍空 = 🟡 未开放 |
| 登录墙 | 需账号 | 让用户在本机 Chrome 登录一次，会话保持后继续 |

- playwright MCP 无需前置（自动拉起），适合快速抓取；**涉及登录态/表单操作优先用 Chrome MCP**
- 实测步骤 ≤ 3 次导航/家，控制成本；未开放单位不实测，只给预计时间

### 登录态维护（解决"每次都要重新登录"）

**原因分层**：① 网站端 token 过期（招聘系统 51job/国聘/牛客等 token 有效期短或"记住我"默认不勾，浏览器无法根治）② Chrome 被反复 kill 或启动参数不一致导致 profile 变更（登录态全丢）。

**解决方案**：
1. **永远用固定启动脚本** `bash tools/chrome-mcp-start.sh`——参数写死（同一 user-data-dir），重复运行会复用已运行的 Chrome，绝不裸手敲启动命令
2. **不要频繁 kill Chrome**：登录态在 profile 里持久保存，但 Chrome 非正常退出可能写不完整；让后台任务常驻
3. **登录时勾"记住我/7天免登录"**（若有），并把账号密码交给 Chrome 密码管理器（profile 的 Login Data 会自动保存）
4. **token 过期无法避免 → 用检查步骤兜底**：实测时若页面跳登录页（URL 含 login/注册页、有"登录/注册"按钮无用户信息），提示用户"请在本机 Chrome 手动登录一次"，登录后该会话内持续有效
5. **登录成功的标志**：页面右上角出现用户头像/名字（如九洲系统"你好，张洵"）——有则登录态正常，可直接看"我的投递"

## 运营商平台操作手册（2026-08-10 实测验证）

### 中国电信 — job.chinatelecom.com.cn/wt/TELE/web/index
1. 打开校园招聘页 → 默认显示"招聘单位(N)"列表
2. 工作地点筛选点"展开全部" → 点用户省份（如"四川省"）
3. 判定：省份点后**单位列表变化/出现该省单位岗位** = 🟢；单位列表仍无该省单位 = 🟡（如 2026-08-10：14 家单位无四川公司，四川未上线）
4. 注意：电信"岗位陆续更新上线中"，四川公司可能后放，需持续盯

### 中国移动 — job.10086.cn
1. 首页 → 点"校园招聘"
2. 左侧单位导航（集团总部/省公司/专业公司/直属单位）找用户地区：如"四川公司""成都产业研究院""集团总部内审部（天津、武汉、成都）分部"
3. 点地区单位 → 判定：岗位区有数据 = 🟢；**岗位区为空/busy 无数据 = 🟡 未开放**（2026-08-10 实测：框架就绪但岗位空）
4. 公告区看有无当年秋招公告（2026-08-10 只有系统升级/春招公告 = 未开放）

### 中国联通 — zglt.zhaopin.com（智联专区）
1. 打开主入口 → 看标题：是"202X届校园招聘"还是"202X暑期实习生计划"
2. 标题是**上一届/实习计划** = 🟡 未开放（2026-08-10 实测：仍为"2026暑期实习生计划"）
3. 联通官网招聘栏目 chinaunicom.com.cn → 校园招聘 → 投递链接同样判断

### 中国铁塔 — zhaopin.chinatowercom.cn（官方唯一）
1. 打开 → 有防诈骗提示页（本网站为唯一招聘网站，笔试面试通知仅 @chinatowercom.cn / @italent.cn 邮箱）→ 点"我已阅读并同意"
2. 导航点"校园招聘" → 判定：列表有数据 = 🟢；**"没有找到相应的数据" = 🟡 未开放**（2026-08-10 实测）
3. 历史规律：每年 10 月中-11 月中报名，2027 届预计 2026 年 10 月开

## 反诈骗要点（实测时一并核对）
- 铁塔这类提示页本身就是官方渠道判据：**唯一官网 + 邮箱后缀**（@chinatowercom.cn）
- 任何"付费内推/保过/保证金/索要验证码"与官方无关（详见 anti-fraud.md）
