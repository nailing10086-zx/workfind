# workfind — 央国企招聘信息查询

## 任务
用户输入央国企名称，查询该单位招聘信息。单位范围不限——可查任何一级央企、省属国企、市属国企、区县国企。

## 用户指令说明

| 用户输入 | 行为 |
|:--------|:----|
| `[单位名称]` | 查该单位招聘信息 + 难度评估 + 薪资晋升分析 |
| `[单位名称1]、[单位名称2]...` | 查指定的多家 |
| `全部` | 先搜国资委官网获取最新央企名录，逐一查询含难度评估 |
| `全部 广东` | 搜该省国资委官网获取省属国企清单，逐一查询含难度评估 |
| `全部 [省/市名]` | 搜该省/市国资委官网获取国企名录，逐家查询 |
| `全部 广东 地市` | 搜该省各地市市属国企名录，逐一查询 |
| `攻略` | 输出国企晋升路径、关系运作、转政府通道的综合知识 |
| `攻略 [单位名]` | 针对该单位的晋升空间和转政府分析 |
| `简历 [岗位名称]` | 根据候选人简历（如有）或 arguments 提供的信息，针对该岗位生成定制简历 |
| `简历 [单位名] [岗位名]` | 针对该单位的特定岗位定制简历 |
| `简历诊断 [岗位名称]` | 针对该岗位诊断候选人简历缺口：JD关键词对齐、缺失经历、改写建议 |
| `宣讲会 [单位名]` | 查该单位近期校招宣讲会/投递时间节点（秋招场次） |
| `秋招日历` | 输出央国企秋招时间线（读 references/campus-calendar.md，已核实/预计开放） |
| `内参 [话题]` | 央国企求职内参：晋升/关系/转政府/结构化面试/选岗方法论/避坑（读 references/job-advice.md） |
| `投递 记录 [单位] [岗位] [状态]` | 记录投递事件到本地记忆（状态：已投/笔试/面试/offer/拒）；`投递 列表` 查看 |
| `投递 列表` | 查看全部投递记录 |
| `投递 结果 [单位] [岗位] [结果]` | 记录投递最终结果（offer / 拒 / 放弃），用于模型校准 |
| `投递 分析` | 统计投递命中率与环节转化率，对比模型预测区间 |
| `模型 校准` | 用真实投递结果校准基线/修正因子（样本≥10，每次≤2pp）|  
| `数据 贡献` | 询问用户是否匿名贡献脱敏数据改进模型（不涉及个人信息）|

## 结构化参数（推荐，过滤后再跑，省时间省配额）

arguments 按 YAML 提供；**缺省时按候选人简历（如有）里的筛选条件执行**：

```yaml
地区: 不限                  # 限定【办公地点=岗位工作地】，不是公司总部！如：广东 / 四川 / 成都 / 不限
# 注意：总部在外地的央企，只要本地有岗位/办公实体仍可投；总部地点只作背景信息，不影响筛选
行业: [运营商, 军工装备, 数据科技]  # 空 = 不限
岗位: [综合管理, 党建, 审计, 数据分析, 信息安全]  # 只看这些方向
排除: [纯销售, 客户经理, 写代码技术岗]   # 明确不看的岗
只查已开放: true           # true：未开放单位只给预计时间，不做完整输出，省配额
分组: true                 # true：按行业分组跑批，每组独立缓存文件
```

跑批节奏原则：
- **不要全量扫 60+ 家**。按行业分组，每组一个独立查询批次。
- **候选单位预筛（论文基线口径 ≥10%）**：录用参考模型的基线是"申请→回调/面试 10-15%"（通用劳动力市场简历审计，Bertrand & Mullainathan 2004 AER 等），因此**学历达标 + 无硬约束冲突的单位修正后通常都 ≥10%**。预筛只需排除：🔴 硬约束冲突（纯销售/写代码）、学历不达标、明显不对口（文艺院团/物业/纯销售制造等）。**旧口径（匹配分×竞争×关系）误过滤的单位——无关系或竞争激烈但学历达标的——应放回显示**，机会大小由修正因子自然体现。预筛用本地脚本按候选人简历关键词打标即可（零成本，脚本放 `招聘结果/` 运行目录，不进仓库）。
- 组内优先查"已开放/临近开放（2周内）"的单位；未开放且距开放>1个月的，只记录预计时间，不做完整输出。
- 大厂/上市公司只在用户点名或画像里标记"高薪备胎"时查。

## 第〇步：读取候选人简历（可选，通用）

候选人信息用于匹配度评估；**没有简历也能正常跑**（输出客观岗位信息）。

简历来源（任选其一，优先级从高到低）：
1. **用户直接拖入现成简历**：arguments 里 `简历: <路径>` 填用户拖入的文件路径（.md/.txt/.docx/.pdf 均可）
2. arguments 里带候选人背景描述（无文件时用）
3. 缺省自动尝试常见位置：

```bash
ls $PWD/简历/*.md $PWD/简历/*.txt 2>/dev/null
ls $PWD/*简历*.md $PWD/*简历*.txt 2>/dev/null
```

读取方式：
- .md/.txt：`cat` 直接读
- .docx/.pdf/.doc/.rtf/.odt 等：用 firecrawl_parse 解析（本地文件用 filePath 参数）

规则：
- 简历存在：匹配度评估以简历为准（教育/证书/经历/硬约束/筛选条件/已投记录），arguments 里的信息作补充
- 简历不存在：用 arguments 里提供的候选人背景评估；再没有 → 只输出客观岗位信息，匹配度标"需自行判断"
- **简历可由 resume-craft skill 生成，也可由用户直接提供现成文件**；本 skill 不绑定任何特定用户
- 简历里的筛选条件（地区/行业/岗位/排除）是跑批的默认过滤依据，除非 arguments 显式覆盖

读取规则：

如果本地文件存在，用它作为企业清单，逐家搜索招聘信息。
如果本地文件不存在，再走网络搜索。

## 第三步：网络搜索补充（带成本控制）

### 当用户说"全部"（查全国一级央企）
1. 先搜 `国资委央企名录` 获取最新一级央企清单（约99家）
2. 对每家央企，搜索其旗下主要二级子公司/省公司（如电信→天翼云/各省电信）
3. 按行业逐类搜索招聘信息
4. 每类搜索各央企**省公司/地市公司**的招聘信息

### 当用户说"全部 某省"（查省属国企含子公司）
1. 搜索 `[省名] + 省国资委 + 省属企业名单` 获取完整清单
2. 搜索 `[省名] + 省国资委 + 监管企业名录` 作为补充
3. 获取名单后，对**每一家**省属国企，搜索 `[企业名] + 子公司` 获取其二三级子公司
4. 合并全部名单后逐家查询招聘信息

### 当用户说"全部 某市"（查市属国企含子公司）
1. 搜索 `[市名] + 市国资委 + 市属企业名单` 获取清单
2. 对**每一家**市属国企，搜索旗下子公司
3. 逐家查询招聘信息

### 当用户说"全部 某省 地市"（查全省各地市）
1. 先获取该省全部地级市列表
2. 逐市搜索 `[地市名] + 市国资委 + 市属企业`
3. 合并后逐一查询

### 当用户指定具体单位时
1. 先查本地数据库/缓存看该单位是否存在
2. 搜 `[单位名] + 校园招聘官网`
3. 搜 `[单位名] + 2024 校园招聘`、`[单位名] + 2025 校招`、`[单位名] + 2026 校招`
4. 搜国聘网/智联招聘补充岗位信息

### 成本控制（关键）
- **搜索顺序**：先搜 `[单位名] + 2026 校招`（最近一年信息最有用）→ 缺历史再补 2025/2024。不要每次三家历史全搜。
- **已确认 2027 届开放的单位**：只搜 2027 届岗位/入口/截止，不搜历史。
- **未开放且距预计开放 > 1 个月**：只记录预计时间（按 2026 届推算），不展开搜索。
- **`只查已开放: true`**：跳过所有未开放单位的搜索，只输出预计时间行。
- 单次跑批总搜索次数控制在 30 次以内；超出后只深挖匹配度高的单位。

## 第三步·五：官方平台浏览器实测（防误报核心，必须）

**判定"已开放"的唯一可靠依据 = 打开官方网申系统，数出用户地区的岗位数**。新闻/公告只能证明集团启动，不能证明用户地区有岗。

```bash
cat $PWD/.reasonix/skills/workfind/references/platform-check.md 2>/dev/null
```

操作（每家 ≤ 3 次导航，控制成本）：
1. 用 Chrome MCP（`mcp__chrome-devtools-mcp__*`）或 playwright（`mcp__playwright__*`）打开官方校招入口（优先 company-sources.yaml 登记入口）
2. 定位"招聘单位/省公司"列表 → 找用户地区单位；用地区筛选点用户省份
3. 记录实测结果，据此定状态标记：
   - 单位列表有本地区单位 **且** 岗位数 > 0 → `🟢 已开放（本地区有岗）`
   - 集团启动但本地区单位未上线 / 筛选无岗位 → `🟡 集团已启动（本地区岗位未上线）`
   - 主入口还是上一届（如暑期实习）或岗位区空（"没有找到相应的数据"）→ `🟡 未开放`
4. **Chrome MCP 前置**：若报"Could not connect to Chrome"，按 platform-check.md 用 bash 拉起 9222 调试端口 Chrome（`"/c/Users/22174/AppData/Local/Google/Chrome/Application/chrome.exe" --remote-debugging-port=9222 --user-data-dir="C:/Users/22174/.chrome-devtools-profile" &`，curl 验证后再继续）；**建议优先用 Chrome MCP**（登录态可复用），playwright 无需前置
5. 未开放单位不实测（只给预计时间）；已开放单位实测后把入口/日期追加到 company-sources.yaml
6. **第三方聚合站只作线索，岗位状态必须回官方系统核实**：jobui/牛企/中公/高顿等聚合站会挂**已下架的旧岗位**（实例：中航无人机党建岗在 jobui 显示"7小时前更新"，官方系统实为"已停用"）——聚合站信息一律标"需核实"，以官方系统为准
7. **用户已投岗位的核实：让用户登录官方系统，直接看"我的投递"**——比搜公告准（实例：九洲登录后"我的投递"显示实际投的是党建/数据中心/纪检3志愿，纠正了记忆里的"科技管理"误记）；投递记录含志愿顺序/公司/时间，是核对已投状态的最权威依据
8. **核实岗位时按用户岗位方向过滤岗位数**：单位开放≠有对口岗——实例：天翼云成都9岗中6个研发+管培生偏销售，实际只有产品经理1个可投；要筛出"用户方向∩本地区"的真实可投数

### 网站链接处理
- 所有网站链接标注"需审查"
- 不确定正确的不写
- **查单位前先确认是否重组/更名**：省属国企近年重组频繁（实例：川投+能投+川煤 2025 年重组为"四川能源发展集团"），旧官网域名可能被私服/影视站占用（反诈警示）——搜到旧域名先核实工商/国资委最新名称，域名被第三方占用的一律标风险
- **开放日/暑期实习公告 ≠ 校招正式岗**：成飞/航发/东方电气的暑期开放日、实习项目不能当正式校招岗标记，要区分标注（开放日=提前批体验性质，正式岗看秋招批次）
- **官方系统里的"长招"老岗位（无截止时间）当届可投**：中航无人机 2026-06 发布的岗位无截止时间，2027 届仍可投——判断可投性看"是否停用/下架"，不能只看发布年份

## 输出格式

**文件开头先给汇总表**（一眼看到现在能投什么），再逐家完整输出：

**状态标记判定规则（必须遵守）**：
- `🟢 已开放（本地区有岗）`：集团/公司公告开放 **且** 用户所选地区/单位的岗位**已上线**（官方平台岗位数 > 0）——两者缺一不可
- `🟡 集团已启动（本地区岗位未上线）`：集团/总部公告开放，但用户地区单位岗位为 0——需盯平台等放岗
- `🟡 待开放`：集团也未启动
- `🔴 不符合筛选`：硬约束冲突/学历不达标/不对口

**地区岗位核实（防误报，关键）**：发现集团"校招全面启动"公告时，**必须**到官方招聘平台按用户所选地区/单位核实实际岗位数（用浏览器实测官方网申系统，见第三步·五）：
1. 岗位数 > 0 → 才标"🟢 已开放可投"
2. 岗位数 = 0 → 标"🟡 集团已启动（本地区岗位未上线）"，并给出"盯平台等放岗"指引
3. **禁止把集团公告直接当成用户地区有岗**（集团启动 ≠ 用户办公地点有岗位）
4. 判"已开放"**必须实测官方平台岗位数**，不能只凭新闻/公告/第三方转载

```
### 🟢 已开放可投
| 单位 | 办公地点(工作地) | 岗位匹配分 | 截止 | 风险⚠️ |
|:-----|:--------|:------:|:----:|:----:|
| ...  | ...     | 85    | ...  |      |

### 🟡 待开放（预计时间）
| 单位 | 预计开放 | 岗位匹配分 |
|:-----|:--------|:------:|
| ...  | ...     | 78    |
```

对每个单位输出（**每家保持完整 7 大块**，顶部加状态标记）：

```
## [单位全称] 🟢已开放 / 🟡待开放 / 🔴不符合筛选
⚠️ 风险提示：<命中反诈骗清单时写，否则省略>

### 基本信息

### 录用参考（论文实证+中国校招锚点，见 references/job-advice.md）
- **公式（2026-08 实证校准）**：`录用概率 = 申请→面试回调率 × 笔试通过率 × 面试→offer通过率`——不再把"回调率"当"录用率"
- **回调率**：海投普通简历 **8-15%**（简历审计 AER + 中国案例：投130→面9≈7%）；HR 行业筛选基准 15-25%（Boss 渠道 8-15%）
- **面试→offer 分场景**：央国企差额 **30-50%**（5HC/10过面）/ 大厂多轮 **15-25%**（Recruitee 20%）——不用 60-80%（原误借 SF Match 医学匹配）
- **申请→offer 总转化**：普通简历 **2-4%**（案例：投40→1offer=2.5%）——单岗概率的真实量级
- **院校档次两档（2026-08 新增）**：海投热门岗双非 ×0.6-0.7（机筛卡，案例：四非投130+仅7%回调）/ 定向央国企岗 ×0.9-1.0（愿扎根反占优）
- **竞争度档（2026-08 新增）**：低竞争（<30:1，市州/军工管理岗）×1.2 / 高竞争（>100:1，大厂/省行热门）×0.7
- **时效分层**：经典文献=理论框架（信号/人力资本/效度/强关系，因果机制不过时）；**数值锚点优先近年实证 + 中国 2025/26 校招数据**（2025 届硕士起薪 13749 元/月；73.5% 企业用 AI 简历初筛；72.4% 学生参与 AI 面试——AI 时代简历关键词结构化与 AI 面试准备价值上升）
- 简历修正（**每项标论文依据，保守取值**）：学历达标×1.0-1.2（Spence 1973）；证书对口×1.2-1.5（AI Skills 2026）；经历对口×1.2-1.5（Becker 1964）；**关系：强关系×1.8-2.0 / 弱关系×1.3-1.5（边燕杰 ASR 1997：中国场景强关系>弱关系）**；定向投递×1.5（信号理论）；未备考笔试×0.5-0.8、**未准备面试×0.6（教育部调研：紧张 49.95%/表达欠缺 49.46% 为失败主因）**（Schmidt-Hunter）
- **关系作用边界**：关系只作用于简历关/分岗；笔试面试按实际准备度计算，不叠加关系加成
- 录用概率 = 回调率×修正连乘 × 笔试通过率 × 面试→offer，**输出区间而非单点，封顶 50%**（防虚高）
- **计算纪律（必须遵守）**：组合概率**只算已投岗位**；输出分两档——`当前已投概率`（事实，只含已投）与`投满后概率`（目标，含计划投），并列标注不得混淆；每个数字给完整连乘过程，禁止粗估（详见 references/job-advice.md"计算纪律"）
- 定性评级：机会 弱/中/强；排除项命中（纯销售/写代码）直接 🔴
- **多单位按修正后区间排序，优先投区间高且可行动的**
- **解释义务**：用户问"参考区间/概率怎么算的"时，必须输出完整计算过程（论文基线 → 每项简历修正及取值 → 连乘 → 区间），并逐项标注来源权威性（同行评审顶刊 ✅ / arxiv 预印本 ⚠️未同行评审，仅方向参考）——只给结果不给过程视为违规
```

## 用户说"攻略"时的知识库

当用户说"攻略"或"攻略 [单位名]"，参考以下知识回答：

### 国企晋升路径
- 央企体系：L1-L14职级，L9室经理(副科)是普通人天花板，L10部门副经理(正科)需机遇+关系
- 省属国企：处级体系，中层正职是普通人上限，再往上需省委组织部管理
- 晋升速度：联通>电信>移动（联通人少升得快，但薪资低）
- 去省公司：电信地市→省公司15-20%，移动5-10%，联通省公司直接进省平台
- 运营商地市公司到省公司的路径：借调→省公司项目组→正式调动

### 国企→政府转调
- 前提：必须在国企做到中层以上（副处级/相当于省属国企部门副职）
- 省属国企干部归省委组织部管，转政府通道比央企分公司通畅
- 央企分公司干部管理权限在集团总部，和地方交流少
- 市场化子公司（天翼安全/天翼云）干部不纳行政序列，转政府基本没戏
- 公共管理硕士在转政府时是加分项（政府认这个学历）

### 关系运作
- 厅级关系在本地级市最管用，跨市/跨省效果递减
- 关系能帮你：进门+分好部门+关键时候推一把
- 关系不能帮你：免笔试面试、换掉公示名单
- 现在国企招聘必须公开，但条件可以"量身"（如要求CISP证书+运营商审计经验）
- 关系在移动比在电信更值钱（移动政企业务依赖政府关系）

### 不同级别国企的性价比
- 省公司 vs 地市公司：省公司平台大但难进，地市容易进但天花板低
- 省属国企 vs 央企：省属转政府容易，央企薪资高体系大
- 运营商 vs 其他央企：运营商晋升清晰但薪资中等
- 二级子公司 vs 总部：子公司容易进但发展空间有限
